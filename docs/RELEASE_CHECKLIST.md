# Release Checklist

Before a public release or tagged version:

1. Confirm the working tree and Git history contain no real credentials or private runtime data.
2. Run lint, typecheck, tests, and production build.
3. Confirm paid generation, paid autopilot, YouTube upload, and public publishing are disabled by default.
4. Review dependency and provider changes.
5. Confirm README, security policy, license, and third-party notices remain accurate.
